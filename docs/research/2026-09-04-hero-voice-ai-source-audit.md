# Hero-Voice-Ai primary-source audit

Date: 2026-09-04 (Asia/Bangkok)
Scope: source and history of `Aoacademy2025/Hero-Voice-Ai`; comparison with this repository's Hero AI Voice/RunPod integration. No live production mutation or paid benchmark was performed.

## Decision

**Do not deploy or merge upstream `main` wholesale.** It is not a drop-in replacement for the production worker, its supply chain is not reproducible, and commercial use is blocked pending written licensing clearance:

1. The OmniVoice **code** is Apache-2.0, but its official model card says the **pre-trained model is CC-BY-NC** because of training-data constraints. That is incompatible with an ordinary paid/commercial Hero AI service unless the model owner grants separate rights or the checkpoint is replaced. The embedded audio tokenizer also carries the Boson Higgs Audio 2 Community License, including attribution/AUP obligations and an expanded-license threshold above 100,000 annual active users. [OmniVoice model revision `c5fdb5c`](https://huggingface.co/k2-fsa/OmniVoice/blob/c5fdb5ccb189668d56333f77ba2629f4cd7535f4/README.md#license), [embedded tokenizer license at the same revision](https://huggingface.co/k2-fsa/OmniVoice/blob/c5fdb5ccb189668d56333f77ba2629f4cd7535f4/audio_tokenizer/LICENSE), [OmniVoice code license at `346bb75`](https://github.com/k2-fsa/OmniVoice/blob/346bb75330980a236540d61a0808d00767c0973b/LICENSE).
2. `Hero-Voice-Ai` has no `LICENSE` file and GitHub detects no license. Its README statement that the project code is “ours” is not a copyright license or redistribution grant. Treat its wrapper code and bundled audio as all-rights-reserved until the owner supplies an explicit license. [audited tree at `f9b6c0a`](https://github.com/Aoacademy2025/Hero-Voice-Ai/tree/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37), [GitHub license endpoint](https://api.github.com/repos/Aoacademy2025/Hero-Voice-Ai/license), [README at `f9b6c0a`](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/README.md#license).
3. Upstream's RunPod handler does not emit `contract_version`, `worker_version`, or `catalog_version`; it catches exceptions into a successful `{error: ...}` output. The current app rejects that output under its v2 response validator. [upstream handler `f9b6c0a`](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/runpod_handler.py#L98-L160), [current validator](../../src/lib/omnivoice.ts#L225-L265), [current worker response](../../services/omnivoice-runpod/handler.py#L106-L121).

This is a technical/source audit, not legal advice. Legal approval is a hard gate.

## How cloning works

This is zero-shot cloning, not per-user training. `create_voice_clone_prompt(ref_audio, ref_text)` encodes a short reference; generation conditions on that prompt. One-shot `/clone` creates three stochastic candidates (`class_temperature=0.8`) and returns the candidate with the highest blended speaker-similarity/pitch-variation score. Persistent `/voices` instead normalizes the uploaded file to 24 kHz mono WAV, stores the WAV plus `ref_text` in filesystem + SQLite, and builds/caches the prompt on first later use. [official OmniVoice cloning API at code commit `346bb75`](https://github.com/k2-fsa/OmniVoice/blob/346bb75330980a236540d61a0808d00767c0973b/README.md#voice-cloning), [upstream prompt path](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L252-L270), [clone endpoint](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L695-L783), [voice library](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/voice_library.py).

Current Hero AI already keeps this concern on the safer side of the boundary: explicit rights acknowledgement, admin-only/private rollout, 5–15 s normalized WAV, private `0600` storage outside `public/`, per-user Prisma ownership, a 10-voice limit, and no reference bytes in durable job JSON. It sends the owned reference to RunPod only for the active clone job. [storage](../../src/lib/user-voices.server.ts), [collection route](../../src/app/api/omnivoice/user-voices/route.ts), [item route](../../src/app/api/omnivoice/user-voices/%5Bid%5D/route.ts), [clone verification assertions](../../scripts/verify-hero-voice-clone.ts).

## Security and privacy findings

### Critical/high

- **Fail-open authentication.** If neither `TTS_CREDITS_DB` nor `TTS_API_KEY` is set, `auth()` accepts every request. The Dockerfile does not require either variable and defaults CORS to `*`. A missing secret therefore exposes synthesis, cloning, transcription, enhancement, and persistent voice creation. [auth](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L317-L340), [Docker defaults](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/Dockerfile#L39-L45).
- **Custom reference audio is publicly retrievable.** `/voices/{voice_id}/preview` deliberately has no auth, returns the original custom reference, and marks it `public, max-age=86400`. A random `cv_...` token reduces guessing but is a bearer URL that can leak through logs, history, referrers, screenshots, or returned metadata. [preview endpoint](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L497-L511).
- **Tenancy is API-key tenancy, not Hero-user tenancy.** Credit mode stores the raw API key as the owner. Single-key or no-auth mode maps everyone to owner `public`, so every caller sharing that key can list/use/delete the same persistent voices. Keys are stored in plaintext SQLite and the management CLI prints them. [owner mapping](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L352-L379), [credit schema](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/credits.py#L53-L74), [key CLI](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/scripts/manage_keys.py).
- **Unbounded attacker-controlled work.** FastAPI reads entire uploads into memory and has no upload-byte, request-body, text, name, or ref-text ceiling. The RunPod handler similarly accepts unbounded base64/text and does not validate base64 strictly. Audio parsing, ASR, Demucs, similarity scoring, and three generations amplify denial-of-service cost. [upload paths](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L695-L778), [persistent upload](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L803-L848), [RunPod decode](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/runpod_handler.py#L105-L140).
- **Deletion is not a retention guarantee.** One-shot temp files are removed in `finally`, but persistent voices have no TTL, retention policy, backup erasure process, or orphan reconciliation. Creation writes the WAV before the DB insert and does not clean it if the insert fails; deletion removes the DB row first and ignores file-deletion failure. [library](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/voice_library.py#L54-L94).
- **Billing is fail-open and not reserved.** Authorization checks only that balance is positive before generation; charging happens afterward, may make a balance negative, and server-side charge exceptions are logged then treated as zero cost. Multi-pod safety is explicitly unsupported. [charge path](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L343-L349), [ledger](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/credits.py#L105-L150).

### Medium/observations

- No direct request-controlled URL fetch, shell command, `eval`, or `exec` was found. SQL statements use parameters; generated custom IDs prevent normal path traversal. The upload filename controls only a temporary-file suffix, so traversal is not apparent, but a pathological suffix can still create filesystem errors. The main RCE exposure is native media parsing of untrusted audio (ffmpeg/libsndfile/Demucs stack), which needs sandboxing, patched pins, resource limits, and fuzz tests.
- Returned preview URLs are built from `request.base_url`; without trusted-proxy/Host validation this permits host-header poisoning of returned links, though not server-side request forgery. Gemini fallback uses a fixed Google origin and an operator-controlled model name, not a request URL; its API key is placed in the query string, increasing accidental proxy/error-log exposure risk. [preview URL construction](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/server.py#L485-L494), [Gemini request](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/gemini_translit.py#L74-L97).
- Watermarking is fail-open and can be disabled. There is no detector endpoint, audit event, or test proving detectability for this 24 kHz output after MP3/AAC encoding, editing, speed changes, or the product render pipeline. It must not be described as a guaranteed safety control. [watermark implementation](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/core/watermark.py).
- The current Hero AI path is materially safer: Clerk identity, fail-closed server/clone flags and allowlist, consent, private/no-store reference playback, strict input/output bounds, durable submit/poll/cancel, one-attempt unknown-POST handling, app-owned quota/refunds, and privacy-safe logs. Preserve these controls. [policy](../../src/lib/omnivoice-policy.ts), [provider](../../src/lib/omnivoice.ts), [current handler](../../services/omnivoice-runpod/handler.py), [managed-worker ADR](../adr/0003-managed-omnivoice-audio-worker.md).

## Infrastructure impact

Current production design is one GPU RunPod Serverless worker, scale-to-zero, `workersMax=1`, FlashBoot, 20 GB container disk, CUDA 12.1, 600 s endpoint execution timeout, and an 800 s initialization allowance. The worker requires CUDA and serializes generation. [provisioning script](../../scripts/provision-runpod-staging.ts#L55-L97), [current worker](../../services/omnivoice-runpod/handler.py#L26-L38).

Upstream claims roughly 2.5 GB VRAM, but provides no measured tip benchmark or image size. Adopting the new optional stack adds runtime-loaded faster-whisper `large-v3-turbo`, Demucs `htdemucs`, and AudioSeal weights/cache plus CPU/RAM/VRAM and cold-start work. Its Docker image cannot be reproduced from an ordinary non-recursive clone because it requires initialized `OmniVoice/` and a locally supplied ignored `model/`; it is a FastAPI Pod image, not the current Serverless image. [deployment guide at `f9b6c0a`](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/DEPLOY_RUNPOD.md), [Docker](https://github.com/Aoacademy2025/Hero-Voice-Ai/blob/f9b6c0a4a9adcf2fb44f35c9b35a44c007127c37/Dockerfile).

## Objective staging gates

Run only after the code/model/reference-audio license blockers are cleared. Build a new immutable `linux/amd64` image and new staging endpoint; never mutate the production template.

1. **Reproducibility/security:** pin Hero wrapper commit, base digest, every direct/transitive Python dependency, OmniVoice code/model revision, all LFS SHA-256 values, and ASR/Demucs/AudioSeal checkpoints. Build twice from a clean clone with networking disabled after an explicit fetch stage; require identical manifest/SBOM and no runtime downloads. Static/container scanning must have zero unresolved critical/high CVEs.
2. **Contract abuse:** retain current v2 tests and add malformed codec/polyglot/truncated audio, invalid base64, 8 MB + 1 byte, 800 chars + 1, extreme metadata, decompression/decoder bombs, cancellation, and output >7 MB. Require 100% coded failures, no completed `{error}` jobs, bounded RSS/temp disk, and zero raw script/audio/key material in logs.
3. **Tenancy/deletion:** two users and two admins attempt list/read/use/delete across tenants; require zero cross-tenant success. Verify reference preview is authenticated `private, no-store`. Inject DB/filesystem failure at each create/delete step; require no orphan files/rows. Demonstrate erasure from primary storage and document backup expiry.
4. **Paired audio suite:** compare current immutable production image against candidate on the same 48 voices, at least 30 representative Thai scripts (numbers, dates, currency, names, English/code-switching, punctuation, 700-char chunks), three generations each. Add at least 10 rights-cleared clone references across sex/age/noise/accent and three outputs each. Report Thai CER/WER, reference-output speaker similarity, clipping/silence/duration, and blinded human naturalness/pronunciation MOS. Pass only if candidate CER is no worse by more than 2 absolute percentage points, no individual script exceeds the existing 10% CER failure floor, clone-similarity median does not fall and 5th percentile falls by no more than 0.05, and paired MOS lower 95% confidence bound is above `-0.2` versus production.
5. **Behavioral A/B:** isolate each change (normalization, `0.65` speed, temperature `0.4`, guidance `2.0`, pitch-weight ranking, Demucs). No bundle-only conclusion. Require spoken text to round-trip to the app's canonical `speechText`; caption end error ≤100 ms per chunk and concatenated duration within the plan/quota reservation.
6. **Performance/capacity:** at least 10 true scale-to-zero cycles plus 100 warm requests and a burst at configured queue depth. Record p50/p95/p99 queue delay, cold start, execution, RTF, peak VRAM/RAM/temp disk, image pull bytes, failures, and cost/audio-minute. Hard gates: every accepted job stays under RunPod's 600 s execution timeout, the app's 540 s default provider budget (or an explicitly changed durable budget), 7 MB worker output, and available GPU VRAM; no OOM or orphaned job. Candidate warm p95 and cost/audio-minute must not regress production by >10% without an approved business tradeoff.
7. **Watermark:** on every tested output, verify detector true-positive/false-positive rates before and after the exact Hero encode/render path, MP3/AAC, speed change, trim, and concatenation. A watermark load/apply failure must be observable and fail according to an approved policy, not silently disappear.
8. **Lao:** keep out of product catalog until native-speaker review, Lao ASR/CER measurements, rights/license clearance for all eight WAVs, and app contract/UI/timing tests pass.

## Safe rollout and rollback

- Prefer selective ports into the current hardened worker: normalization tables first, then independently tested audio parameters; ASR/enhancement/watermark only if the product needs them. Do not adopt upstream FastAPI auth, credits, persistence, or public preview endpoints.

Run internal/admin clone canary, then the existing explicit allowlist; expand only after the gates above and a privacy/legal sign-off.

### Clone-only production slice

Use current application `main` as the base, not public upstream FastAPI and not a wholesale `dev_waow` merge.

Required application files/contracts are the `UserVoice` schema/migration; `src/lib/user-voices.server.ts`; `/api/omnivoice/user-voices` and `/[id]`; `src/lib/omnivoice-policy.ts`; `src/lib/omnivoice.ts`; `src/lib/hero-voice-generation.server.ts`; `/api/ai-studio/catalog`; `/api/ai-studio/voices`; and `HeroVoiceClonePanel.tsx` plus its page wiring. Exclude or hide all ordinary-stock and Lao product surfaces: the AI Studio “สร้างเสียง” tab and selector, `RUNPOD_HERO_VOICES`, `/api/omnivoice/voices`, `/api/omnivoice/preview/[voiceId]`, stock use through `/api/ai-studio/voices`, Video Editor's OmniVoice stock provider/routes, worker `mode:"tts"`, primary manifests/WAV previews, and every `voices_lao`, language-catalog, Lao selector, and Lao API addition from `f9701fd`. Keep the clone tab, owned-reference preview/delete, and clone job/result UI only.

**As written, none of the three audited trees is safely deployable as a configuration-only clone-only service.** The couplings are explicit:

1. Application `main` has a separate clone-on flag but no separate stock-off flag. `OMNIVOICE_ENABLED=1` makes the general stock catalog available to allowed users; the shared `/api/ai-studio/voices` accepts both stock and `user_*` IDs, and the page always renders the ordinary voice tab. Clone can therefore not be exposed while reliably hiding stock by environment configuration alone.
2. The current worker and `dev_waow` import `OmniVoiceEngine` from `server.py`; `handler.py` calls `ENGINE.load()` at process start; `load()` requires the primary `voices.json` and registers stock voices. Their Dockerfiles copy and validate stock assets. A truly stock-free image needs a small dedicated clone engine/load path; merely sending only `mode:"clone"` does not remove the bundled stock data or its unresolved rights.
3. Public upstream Docker starts FastAPI with stock `/tts`, `/voices`, unauthenticated custom-reference previews, fail-open auth, and application-incompatible responses. It cannot be made a safe clone-only replacement by hiding UI alone.
4. `dev_waow` is a weaker clone-security base than current `main`: it has no independent `HERO_VOICE_CLONING_ENABLED` gate, drops explicit consent handling, relaxes reference duration to 30 seconds, removes hardened absolute/private storage/path checks and active-job deletion protection, and combines clone/stock/Lao UI. Do not cherry-pick its clone storage/routes/UI as a unit.

Safe import strategy: keep `e212c92` controls and the main v2/durable contract; add an independently fail-closed stock feature gate and enforce clone-only `user_*` IDs server-side; remove/hide the listed stock/Lao routes and UI; then extract a stateless clone worker that loads only the pinned model and clone helpers. Evaluate later changes one at a time (normalization, reference enhancement, ASR/ref-text checks, watermark), with no Gemini upload unless separately approved. Roll out on a new immutable staging endpoint, canary only the clone allowlist, retain the current endpoint/image, and roll back with `HERO_VOICE_CLONING_ENABLED=0`. Commercial rollout remains blocked by the model/code/reference-audio licenses identified above.
