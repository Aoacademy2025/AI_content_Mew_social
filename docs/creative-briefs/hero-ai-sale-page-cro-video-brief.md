# HERO AI Studio - Sale Page CRO Video Creative Brief

Date: 2026-06-08
Owner: Mew
Destination: studio.heroaiengine.com sale page
Primary goal: เพิ่ม conversion จากหน้า sale page ไปสู่ signup / free trial / annual founding purchase

## 1. Executive Summary

เราจะทำวิดีโอทั้งหมด 7 คลิป แบ่งเป็น 2 ประเภท:

1. คลิปขาย/อธิบายระบบ ให้ทีม editor ทำจาก screen recording จริง + motion text + CTA
2. คลิป output จริงจาก HERO AI Studio ให้ระบบสร้างจริง แล้ว editor แก้เฉพาะหัวท้าย/thumbnail เล็กน้อย เพื่อใช้เป็น proof

สิ่งสำคัญที่สุดสำหรับ CRO คือหน้าเว็บต้องไม่ใช่แค่ claim ว่า "สคริปต์ 1 ชุด -> คลิปพร้อมโพสต์" แต่ต้องมีหลักฐานภาพจริง 3 แบบ:

- เห็น workflow จริง
- เห็น output จริงแบบ faceless
- เห็น output จริงแบบ AI Avatar

MVP ที่ควรทำก่อน: คลิป 1, 6, 7

## 2. Core Message

มีแค่สคริปต์ 1 ชุด ก็สร้างคลิปแนวตั้งพร้อมโพสต์ได้ใน workflow เดียว

Supporting message:

- ไม่ต้องออกกล้อง
- ไม่ต้องตัดต่อเองทุกขั้น
- เลือกได้ทั้ง Faceless และ AI Avatar
- มีเสียงพูด ซับไทย B-roll เพลง และ preview/edit ก่อน export
- ทดลอง PRO ฟรี 7 วัน ไม่ต้องใช้บัตร

## 3. Audience

Primary audience:

- Creator ที่ต้องทำคลิปสั้นต่อเนื่อง
- เจ้าของธุรกิจที่อยากทำคอนเทนต์เอง
- Marketer / Social media team
- คนขายคอร์ส ที่ปรึกษา โค้ช และธุรกิจบริการ
- คนที่มีสคริปต์อยู่แล้ว แต่ติดที่ขั้นตอนตัดต่อ

Key objections ที่วิดีโอต้องตอบ:

- ระบบใช้ยากไหม
- Output จริงหน้าตาเป็นอย่างไร
- Avatar ใช้ได้จริงไหม
- ซับไทยและ B-roll ดูดีพอไหม
- เริ่มใช้ฟรีจริงไหม ต้องใช้บัตรไหม
- ทำไมควรสมัครตอนนี้

## 5. Format Requirements

Website embed:

- Main demo / walkthrough: 16:9, 1920x1080, MP4, H.264
- Feature proof clips: 16:9, 1920x1080, MP4, H.264
- Real output samples: 9:16, 1080x1920, MP4, H.264

Social cutdowns:

- Optional 9:16 version for clip 1, 2, 5

Audio and captions:

- ทุกคลิปต้องมี burned-in Thai captions เพราะหน้าเว็บอาจ autoplay muted
- เสียง TTS ต้องชัด ไม่เร็วเกินไป
- Background music เบา ไม่ชนเสียงพูด
- Text overlay ควรอ่านจบใน 1.5-2.5 วินาทีต่อประโยค

Visual direction:

- ใช้ screen recording จริงของระบบ
- หลีกเลี่ยง stock footage ที่ดูไม่เกี่ยวกับ product
- เปิดคลิปด้วยผลลัพธ์ก่อน แล้วค่อยย้อนกลับไป workflow
- ห้ามใส่ตัวเลข social proof ที่ยังไม่มีหลักฐาน เช่น "100+ creators" หรือ "เร็วขึ้น 90%"
- ถ้าโชว์ founding remaining ให้ใช้ footage ล่าสุด หรือเขียนแบบไม่ผูกเลข เช่น "Founding 100 คนแรก"
