- quotes (ถอดความ):

  - "ระบบขึ้น maintenance หลายชั่วโมง" / "พากย์เสียงไม่สำเร็จ" / "ไปต่อไม่ได้"
- root cause จาก audit: transcribe คลิปยาว >~2.5 นาที ตัดช่วงผิด, ตัวนับโควตาเสียงค้าง, HeyGen ตอบช้า/เครดิต HeyGen หมด, Gemini ไม่ส่งเสียงกลับ, Hero AI Image สร้างไม่ครบฉากแล้วหยุดทั้งงาน, avatar full-clip + zoom composite timeout, session Clerk หลุด (401)

## 6. ผู้จ่ายเงินที่มีสัญญาณ churn risk (ไม่ระบุตัวตน)

1. **ลูกค้า PRO รายเดือน, ยกเลิก auto-renew แล้ว (sub=canceled) — 10 ticket ใน window** (มากสุดในกลุ่มผู้จ่าย)
   - ลำดับเหตุการณ์: งานเด้งกลางทำซับ (07-20) → อัปโหลด B-roll ไม่ขึ้น (07-27) → เด้งปิด "เสียนาที" (07-28, ได้ goodwill 3 นาที) → เรนเดอร์ไม่สำเร็จเพราะ key ElevenLabs ผิดประเภท (08-08) → คลิปยาว ~3 นาทีเรนเดอร์ไม่ผ่าน 3 รอบ + ลองซ้ำอีกรอบก็ไม่ผ่าน (08-09/10/16) → key ElevenLabs ยังใช้ไม่ได้ (08-22) → avatar full-clip "ไปต่อไม่ได้" (08-23)
   - **ความเสี่ยงสูงสุด**: ยกเลิก renew แล้ว + ปัญหาเรื้อรังกับ use-case หลัก (คลิปยาว + avatar + เสียงโคลน) — ควรติดต่อเชิงรุกยืนยันว่าแก้แล้ว
2. **ลูกค้า PRO active ที่อยากซื้อรายปีแต่ระบบไม่ให้อัปเกรด** (08-04) — ไม่ใช่ churn แต่เป็น upsell ที่เกือบหลุด; แก้แล้ว ควร follow-up ว่าจ่ายสำเร็จ
3. **ลูกค้า PRO ที่ไม่มี sub (จ่ายครั้งเดียว/PromptPay)** — "พากย์เสียงไม่สำเร็จ" เพราะตัวนับโควตาเสียงค้าง (08-15) และ "render maintenance for hours" (08-23) — จ่ายแบบไม่ auto-renew = ทุก friction คือเหตุผลไม่ต่ออายุ
4. **ลูกค้า PRO active (sub)** — "สร้างคำบรรยายไม่สำเร็จ" 2 ครั้ง (รวมการ์ดสั้น 08-16; ใช้ avatar 08-22) — ทั้งคู่เป็นบั๊กระบบใน core flow
5. **ลูกค้า PRO ยกเลิก renew** ถาม "เปิดใช้หรือยัง" (08-19) — รอฟีเจอร์ก่อนตัดสินใจกลับมา

สรุปเชิงกลยุทธ์: ผู้จ่ายเงิน 6 คนใน window นี้ **4 คนเจอบั๊กใน core render flow** และ 3 ใน 6 อยู่ในสถานะ canceled/ไม่มี sub → เสียงจากผู้จ่ายเงินเกือบทั้งหมดคือ "เรนเดอร์ให้ผ่านและบอกฉันว่าทำไม" ไม่ใช่ฟีเจอร์ใหม่
