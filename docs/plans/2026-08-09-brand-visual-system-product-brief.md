# ระบบแนวภาพประจำแบรนด์ — Product Brief

> สถานะ: เคาะคำตัดสินด้านผลิตภัณฑ์ครบแล้วกับ Mew เมื่อ 2026-08-09
> เอกสารนี้บันทึกคำตัดสินด้านผลิตภัณฑ์ ไม่ใช่แผนลงมือแก้โค้ด

## ปัญหาที่ต้องแก้

Hero AI Image ใช้ prompt กลางจากระบบ ทำให้ภาพของหลายคลิปมีทิศทางคล้ายกัน แม้เนื้อหา นิช และตัวตนของแต่ละช่องจะแตกต่างกัน โดยเฉพาะช่อง faceless ที่ไม่มีหน้า presenter หรือ avatar ให้คนจดจำ ภาพ B-roll จึงต้องช่วยสร้างเอกลักษณ์ร่วมกับสคริปต์ เสียง และลายน้ำ

เป้าหมายยังคงเป็นการสร้างคลิปให้ง่ายเหมือนเดิม ส่วนระบบแนวภาพเป็นชั้นที่ช่วย polish งาน เพิ่มความต่าง และรักษาความสม่ำเสมอของแบรนด์

## หลักการที่เคาะแล้ว

1. Brand DNA คงที่ข้ามคลิป แต่เรื่องที่เล่าและอารมณ์ของแต่ละคลิปเปลี่ยนได้
2. หนึ่งบัญชีมีหลาย Brand Profile ได้ และหนึ่งโปรเจกต์เลือกใช้หนึ่งโปรไฟล์
3. Brand Profile รวมค่าเริ่มต้นของสไตล์สคริปต์ เสียง Subtitle ลายน้ำ/โลโก้ และแนวภาพประจำแบรนด์ โดยแต่ละโปรเจกต์ยังแก้ทับได้
4. V1 เน้นความสม่ำเสมอของภาษาภาพ ไม่รับประกันตัวละครหรือใบหน้าเดิมทุกภาพ และไม่ใช้ LoRA หรือ character conditioning
5. ระบบแยกความหมายภายในเป็น Content Domain, Visual Format และ Visual Treatment แต่หน้าลูกค้าใช้คำง่ายว่า **แนวภาพ**
6. AI วิเคราะห์เนื้อหาเพื่อหา Content Domain, แนวภาพที่เหมาะ และ Visual Beats จากสคริปต์หรือ transcript แล้วจึงประกอบกับแนวภาพของแบรนด์เป็น prompt รายฉาก
7. การวิเคราะห์เกิดแบบ lazy เมื่อผู้ใช้เปิด AutoMix, Hero AI Image หรือส่วนตั้งค่าแนวภาพ และผลลัพธ์ต้อง cache ใช้ซ้ำ
8. โปรเจกต์ pin Brand Profile Revision เพื่อให้การ render ซ้ำไม่เปลี่ยนหน้าตาเงียบ ๆ ตามค่าแบรนด์รุ่นใหม่
9. แนวภาพที่ผู้ใช้เลือกมีอำนาจเหนือคำแนะนำของ AI เสมอ AI ปรับคน วัตถุ ฉาก สี และอารมณ์ให้เข้ากับ Content Domain ได้ แต่ห้ามเปลี่ยน Visual Format หรือ Brand Visual Language เอง แม้จะเห็นว่าแบบอื่นเหมาะกว่า

## แนวภาพ V1

การ์ดหลักมี 5 แบบ:

- ภาพสมจริงแบบหนัง
- ก้างปลาเล่าเรื่อง
- คอมิกเข้มข้น
- อินโฟกราฟิกเข้าใจง่าย
- เล่าเรื่องย้อนยุค

ภาพตัวอย่างของการ์ดหลักทั้ง 5 ใช้ฉาก เนื้อหา และองค์ประกอบ benchmark เดียวกัน แล้วเปลี่ยนเฉพาะ Visual Format/Brand Visual Language เพื่อให้ผู้ใช้เปรียบเทียบแนวภาพได้ตรง ๆ ภาพการ์ดเป็น asset ที่ทีมตรวจแล้ว ไม่เจนใหม่จากสคริปต์ทุกครั้งที่เปิดตัวเลือก

ก่อนสร้าง UI แต่ละแนวต้องผ่าน **Visual Format Benchmark** บน Z-Image: 5 แนว × 3 ฉาก Hook/Explain/Close รวม 15 ภาพแนวตั้ง โดยทุกแนวได้รับสามโจทย์เดียวกัน ได้แก่ Hook ประวัติศาสตร์ลึกลับ, Explain คุณหมออธิบายข้อมูล และ Close การเงิน/ขายของโทนสดใส ตรวจว่าคนแยกแนวได้ ภาพสามฉากมีภาษาเดียวกัน ปรับเข้ากับนิชและอารมณ์ ทำตามฉาก และไม่มีตัวอักษร แนวที่ไม่ผ่านต้องแก้สูตร prompt หรือถอดจาก V1 ก่อน ไม่สร้างการ์ดไว้รอคุณภาพภายหลัง ภาพ benchmark ที่ผ่านสามารถนำมาใช้เป็น asset ของการ์ดได้

จากนั้นต้องผ่าน **Brand Differentiation Benchmark** อีก 6 ภาพ: Visual Format “ก้างปลาเล่าเรื่อง” × Mewsocial Brand Brief จากบัญชี production `duckyhero` เทียบกับ control ก้างปลาแบบไม่มีแบรนด์ × สามฉากเดิม ชุด Mewsocial ต้องรักษาสี เส้น องค์ประกอบ และจุดจำภายในแบรนด์ พร้อมแยกออกจาก control ได้โดยไม่ใช้ LoRA, reference image หรือ character conditioning รวม quality gate ก่อนสร้าง UI เป็น 21 ภาพ

หลักฐาน Brand Brief จาก production แบบ read-only ณ 2026-08-09: โลโก้ “Mew Social Logo-02” เป็นขาว–ดำคอนทราสต์สูง ตัวอักษรหนา เอียง และมีขอบไม่เรียบแบบ cut-out; 18 จาก 30 งาน export ล่าสุดใช้ Subtitle `Kanit` + `stroke` + `karaoke` และสีเน้นฟ้า `#38BDF8`; ค่าเสียงหลักเป็น ElevenLabs; ไม่มี Writing Style ในตาราง Style เดิม ข้อมูลตั้งต้นสำหรับ benchmark จึงเป็นขาว–ดำ + ฟ้า, เส้นหนา/ดิบ/กระฉับกระเฉง, องค์ประกอบเอียงเล็กน้อย และพื้นที่ว่างสำหรับ Subtitle โดยโลโก้จริงยังเป็น overlay และไม่ถูกขอให้โมเดลวาด จุดจำที่ Mew อนุมัติคือวงกลมและลูกศรฟ้า `#38BDF8` แบบปากกา marker ซึ่งปรากฏเป็น motif ซ้ำได้แต่ไม่ใช่ตัวอักษรหรือโลโก้

AI เติมอารมณ์ให้เหมาะกับเนื้อหา เช่น ลึกลับชวนติดตาม ขายของสดใส หรืออธิบายอย่างมืออาชีพ ส่วนการเงิน คุณหมอ และประวัติศาสตร์เป็นหัวข้อของเนื้อหา ไม่ใช่การ์ดแนวภาพ

ภาพ AI ทุกแนวใน V1 เป็น **ภาพไม่มีตัวอักษร** รวมถึงแนวอินโฟกราฟิก ซึ่งใช้รูปทรง ไอคอน แผนภาพ และองค์ประกอบช่วยอธิบาย แต่ไม่ขอให้โมเดลเขียนคำหรือป้ายภาษาไทย ข้อความที่คนดูต้องอ่านเป็นหน้าที่ของ subtitle/headline layer ส่วนโลโก้และลายน้ำเป็นหน้าที่ของ brand-mark layer การแยกชั้นนี้ทำให้ V1 ไม่ขึ้นกับความสามารถด้านภาษาไทยของ Z-Image

การให้โมเดลเขียนข้อความในภาพเป็นความสามารถในอนาคตที่เปิดตาม Image Engine/Model เช่นเส้นทาง GPT Image ผ่าน KIE ที่มี integration อยู่แล้ว ไม่เปลี่ยนความหมายของ Brand Visual Language และไม่อยู่ใน scope V1

นอกจากการ์ดหลัก มีชุดแนวภาพตามกระแสที่ผลัดเปลี่ยนได้ การเลือกชุดตามกระแสมีผลกับคลิปปัจจุบันเท่านั้น จนกว่าผู้ใช้จะสั่งบันทึกเป็นค่าเริ่มต้นของแบรนด์

หมวด **กำลังนิยม** เป็น catalog ที่ทีมงานคัดและเผยแพร่ผ่านหลังบ้าน แต่ละชุดมีชื่อไทย ภาพตัวอย่าง สถานะเผยแพร่ และช่วงวันเริ่ม/สิ้นสุด ทีมปิดชุดที่ตกกระแสได้โดยไม่ต้อง deploy ระบบไม่สร้างหรือเผยแพร่ Trend Pack ใหม่ให้ลูกค้าอัตโนมัติ

เมื่อผู้ใช้เลือก Trend Pack ระบบ snapshot สูตรและรุ่นของชุดนั้นไว้ใน Project Look หรือ Brand Profile Revision การแก้ ปิด หรือถอดชุดออกจาก catalog มีผลเฉพาะการเลือกใหม่ งานเก่ายังเปิดและเรนเดอร์ซ้ำด้วยสูตรเดิมได้

## ประสบการณ์ใน Video Editor

สเต็ป 2 เป็นจุดเลือกค่าที่เกี่ยวกับภาพ โดยไม่เพิ่มสเต็ปใหม่:

1. เลือก Brand Profile แบบรวดเร็ว หรือสร้างใหม่
2. เลือกระดับ B-roll: Stock, AutoMix หรือ Hero AI Image
3. เมื่อเลือก AutoMix/Hero แสดงสรุปแนวภาพที่ AI แนะนำอย่างชัดเจน
4. ผู้ใช้กด “เปลี่ยนแนวภาพ” เพื่อเปิดการ์ดภาพ หรือปล่อยค่าที่ AI เลือกไว้ได้
5. ตามด้วยเสียง เพลง และ avatar ตาม flow เดิม

หน้า **แบรนด์ของฉัน** ใช้สร้างและจัดการ Brand Profile แบบเต็ม ส่วน Editor มีเฉพาะการเลือกและการสร้างแบบรวดเร็ว

สำหรับผู้ใช้เดิม ระบบแสดงทางเลือก **“สร้างแบรนด์จากค่าที่ใช้อยู่”** แล้วนำสไตล์การเขียน เสียง และลายน้ำที่มีอยู่มาเติมในแบบฟอร์มให้ตรวจสอบก่อนบันทึก ไม่มีการสร้าง Brand Profile หรือจับคู่ข้อมูลข้ามช่องให้อัตโนมัติโดยไม่ขอคำยืนยัน

## การตั้งค่า Brand Profile

ใช้ wizard ที่เริ่มจากภาพ ไม่เริ่มจาก prompt หรือ chat:

- เลือกแนวภาพหลัก
- เลือกสีแบรนด์
- ระบุบุคลิกแบรนด์
- ระบุคนหรือฉากแวดล้อมที่ใช้บ่อย
- เพิ่มจุดจำทางภาพ
- เขียน “รายละเอียดเพิ่มเติม” ด้วยภาษาทั่วไป เช่น ลักษณะเส้น วัสดุ อารมณ์ หรือสัญลักษณ์ที่อยากใช้
- เชื่อมสไตล์การเขียน เสียง และลายน้ำเดิม

Brand Profile จำฟอนต์ สี และรูปแบบ Subtitle จากเครื่องมือเดิมเป็นค่าเริ่มต้นของแบรนด์ คลิปใหม่รับค่านี้แต่แก้ทับรายคลิปได้ Visual Format หรือ Trend Pack ไม่เปลี่ยน Subtitle ให้อัตโนมัติ และ V1 ไม่สร้างระบบแนะนำ Subtitle ใหม่

ระบบไม่เปิด raw prompt ให้แก้โดยตรง Visual Notes เป็นความตั้งใจของผู้ใช้ที่ AI แปลงเข้าโครง Brand Visual Language และ prompt compiler เป็นผู้สร้างคำสั่งของโมเดล วิธีนี้ทำให้เปลี่ยนโมเดลภายหลังได้โดยไม่ทำให้ข้อมูลแบรนด์เดิมเสีย

V1 ไม่รับภาพอ้างอิงจากผู้ใช้และไม่ส่ง reference image เข้าโมเดล การ์ดแนวภาพ สี บุคลิก จุดจำ และ Visual Notes เป็น input ด้านภาพทั้งหมดของ V1 เพื่อไม่สื่อว่าระบบรับประกันตัวละคร ใบหน้า หรือรูปแบบเหมือนภาพต้นฉบับ

ปุ่ม **ให้ AI ช่วยออกแบบแนวภาพ** ช่วยเกลาข้อมูลให้เป็นข้อเสนอที่เป็นระบบ แต่จะไม่แก้ค่าใดจนกว่าผู้ใช้ยอมรับ และการกดปุ่มนี้ยังไม่เจนภาพ

ปุ่มนี้ใช้ได้ทุกแผนรวมถึง Free และนับรวมกับเพดานงานประมวลผลข้อความที่ระบบมีอยู่แล้ว ไม่สร้างโควตาใหม่และไม่หักสิทธิ์ทดลองภาพ AI จนกว่าผู้ใช้จะสั่งเจนภาพจริง

Brand Look Preview ใช้ภาพ 3 ภาพ ได้แก่ Hook, Explain และ Action/Close หากเปิดจาก Editor ให้ใช้ Visual Beats ของคลิปจริง หากเปิดจากหน้าแบรนด์ให้ใช้ฉากทดสอบมาตรฐานตามนิช

เมื่อผู้ใช้บันทึก Brand Profile หลังเจนคลิปแล้ว ระบบนำภาพ Hook, Explain และ Action/Close ที่มีอยู่มาใช้เป็น Brand Look Preview โดยไม่ส่งงาน RunPod และไม่หักสิทธิ์ซ้ำ หากสร้างโปรไฟล์จากหน้า “แบรนด์ของฉัน” ก่อนมีคลิป การกดทดลอง 3 ภาพจึงเจนภาพใหม่และนับสิทธิ์ทดลองภาพ AI 3 ภาพจริง สำหรับ Free เท่ากับสิทธิ์ลดจาก 8 เหลือ 5 ภาพในรอบนั้น

## การเจนและการแก้ภาพ

- การ Preview หนึ่งครั้งเป็น logical batch เดียว แต่ส่งงานภาพแบบ durable 3 งานไปยัง Z-Image และโดยปกติใช้ worker ที่อุ่นอยู่รอบเดียวกัน
- “ลองภาพนี้ใหม่” เจนใหม่เฉพาะฉากโดยรักษากฎของแบรนด์เดิม
- “ปรับแนวภาพทั้งช่อง” สร้าง Brand Profile Revision ใหม่สำหรับงานในอนาคต
- ภาพที่มีอยู่แล้วไม่ควรถูกเปลี่ยนหรือเจนใหม่โดยอัตโนมัติเมื่อแก้โปรไฟล์แบรนด์
- การแก้สี บุคลิก จุดจำ หรือค่าอื่นของ Brand Profile อยู่ใน Brand Profile Draft ก่อน การ Preview เป็นทางเลือกและคิดเฉพาะภาพที่เจนจริง เมื่อผู้ใช้กด “ใช้แนวภาพใหม่นี้” จึงสร้าง Revision ใหม่และทำให้โปรเจกต์ใหม่เริ่มใช้ค่านั้น การแก้ฟอร์มหรือ Preview อย่างเดียวยังไม่เปลี่ยน Revision ที่ใช้งานอยู่
- เมื่อแก้สคริปต์หลังมีภาพแล้ว ระบบวิเคราะห์ความเปลี่ยนแปลงและติดสถานะ “ฉากที่เนื้อหาเปลี่ยน” เฉพาะ Visual Beats ที่ไม่ตรงกับเนื้อหาปัจจุบัน ภาพเดิมยังอยู่ ระบบแสดงจำนวนฉากและโควตา/เครดิตที่จะใช้ แล้วเจนใหม่เฉพาะฉากที่ผู้ใช้ยืนยัน ไม่มีการเจนซ้ำทั้งคลิปหรือหักสิทธิ์อัตโนมัติ
- เมื่อเปลี่ยน Brand Profile หรือแนวภาพของคลิปหลังมีภาพแล้ว ระบบหยุดให้เลือกว่าจะ “สร้างทุกภาพใหม่ให้เป็นแนวเดียวกัน” พร้อมจำนวนภาพและค่าใช้จ่าย หรือ “ใช้แนวใหม่เฉพาะภาพที่สร้างต่อจากนี้” พร้อมคำเตือนว่าคลิปจะมีมากกว่าหนึ่งแนวภาพ ระบบไม่เจนใหม่และไม่ผสมแนวภาพโดยอัตโนมัติ

## ระดับความครอบคลุมของแบรนด์

- **Stock:** สคริปต์ เสียง ซับ และลายน้ำรักษาแบรนด์ แต่ไม่รับประกันว่าภาพสต็อกจะมีภาษาเดียวกัน
- **AutoMix:** เฉพาะช่วงที่เป็นภาพ AI ใช้แนวภาพของแบรนด์ ส่วนภาพสต็อกยังแตกต่างกันได้
- **Hero AI Image:** ภาพ B-roll ที่สร้างทุกช่วงใช้ระบบแนวภาพเดียวกัน

## Starter-to-Paid Experience

ผู้ใช้ที่ยังไม่ชำระเงินต้องได้เห็นผลลัพธ์จากสคริปต์จริงก่อนถูกขอให้ตั้งค่าแบรนด์เชิงลึก:

1. ใส่สคริปต์ของตัวเอง
2. เลือกแนวภาพ เช่น “ก้างปลาเล่าเรื่อง”
3. AI วิเคราะห์เนื้อหาและสร้างภาพที่ตรงกับแต่ละ Visual Beat ในแนวเดียวกัน
4. ผู้ใช้เห็นคลิปจริง แล้วจึงถูกชวนให้บันทึกแนวนี้เป็นแบรนด์และอัปเกรดเพื่อผลิตต่อเนื่อง

ระหว่างทดลอง การเลือกนี้เป็น **แนวภาพของคลิปนี้** และยังไม่สร้าง Brand Profile หลังเห็นผลลัพธ์ ระบบจึงถามอย่างชัดเจนว่า “บันทึกแนวนี้เป็นแบรนด์ของฉันไหม” การกดยืนยันจึงสร้างโปรไฟล์และนับโควตาโปรไฟล์ การทดลองหรือปิดหน้าจอไม่ทิ้งโปรไฟล์ขยะไว้ใน Brand Library

สิทธิ์ที่เคาะแล้ว:

- Free ยังมี 5 Render Minutes ต่อ 30 วันตามเดิม
- Free สร้าง Brand Profile ได้ 1 โปรไฟล์
- สิทธิ์ทดลองภาพ AI 8 ภาพเริ่มตั้งแต่วันสมัครและใช้ได้ระหว่าง PRO Trial 7 วัน ผู้ที่ยังไม่ชำระเงินนำสิทธิ์คงเหลือต่อไปสู่ Free จนครบ usage window 30 วันเดิม การหมด Trial ไม่แจกอีก 8 ภาพรอบสอง หลังจากนั้นบัญชี Free จึงรีเซ็ตตามรอบ 30 วัน
- Free แก้รายละเอียด Brand Profile ได้ครบทั้งแนวภาพ สี บุคลิก จุดจำ เสียง และลายน้ำ แต่ค่าเหล่านี้อยู่ใน “ตั้งค่าเพิ่มเติม” เพื่อให้ flow แรกยังง่าย การอัปเกรดขายกำลังการผลิตและจำนวนแบรนด์ ไม่ใช่สิทธิ์กรอกข้อมูลแบรนด์
- ผู้ใช้สามารถใช้ 8 ภาพกับคลิปสั้นประมาณ 30 วินาที หรือกระจายใช้ใน AutoMix
- นาทีที่เหลือยังสร้างด้วย Stock B-roll ได้
- การมีนาทีเหลือไม่ได้ทำให้เจนภาพ AI ได้ไม่จำกัด
- หากคลิปต้องการฉากมากกว่าโควตาภาพที่เหลือ ระบบกระจายภาพ AI ที่มีให้ครอบคลุมทั้งคลิปและลด AI Image Density แทนการแอบเติม Stock ภาพทุกช่วงจึงยังรักษาแนวภาพเดียวกัน แต่เปลี่ยนภาพช้ากว่าแผนจ่ายเงิน
- หากโควตาภาพ AI เหลือเป็นศูนย์ก่อนเริ่มคลิปใหม่ ระบบหยุดก่อนเจนและอธิบายว่าใช้โควตาครบแล้ว ปุ่มหลักชวนอัปเกรดเป็นแผนรายเดือน ส่วนปุ่มรองให้เปลี่ยนไปใช้ Stock ฟรี ระบบไม่ขายเครดิตภาพเพิ่มให้ Free และไม่เปลี่ยนเป็น Stock โดยอัตโนมัติ

หลังอัปเกรด Pro/Business ไม่มีโควตาภาพหรือกระเป๋าภาพอีกชุด ภาพ AI และนาทีที่ใช้เกินแพ็กเกจหักจาก Credit balance เดียวกัน เครดิตรายเดือนของ Pro/Business และเครดิตที่ซื้อเพิ่มเข้ากระเป๋าเดิมทั้งหมด สิทธิ์ทดลอง 8 ภาพจึงเป็นข้อยกเว้นเพื่อ activation ก่อนชำระเงินเท่านั้น

ภาพ AI ราคา 2 เครดิตต่อภาพเท่ากัน ไม่ว่าจะใช้แนวภาพทั่วไป Project Look หรือ Brand Profile การวิเคราะห์ Narrative Source, หา Visual Beats, แนะนำแนวภาพ และประกอบ Brand Visual Language เข้า prompt ไม่คิดเครดิตเพิ่ม ระบบหักเครดิตเมื่อมีการเจนภาพจริงเท่านั้น

เพดาน Brand Profile ใช้กติกา Free 1 / Pro 5 / Business ไม่จำกัด และนับเฉพาะโปรไฟล์ที่ผู้ใช้ยืนยันบันทึกเข้า Brand Library เท่านั้น Project Look ที่ใช้ทดลองหรือ override รายคลิปไม่นับโควตานี้

เมื่อผู้ใช้ลดแผนจนเพดานต่ำกว่าจำนวนโปรไฟล์ที่มี ระบบไม่ลบ Brand Profile หรือ Revision ใด ผู้ใช้เลือกหนึ่งโปรไฟล์ที่ยังใช้กับงานใหม่ได้ตามเพดาน Free ส่วนโปรไฟล์เกินเพดานอยู่ในสถานะอ่านอย่างเดียวและกลับมาใช้งานได้ทันทีเมื่ออัปเกรด

โปรเจกต์เดิมที่ pin Revision ของโปรไฟล์ซึ่งถูกแช่ยังเปิดและเรนเดอร์ซ้ำด้วย Revision เดิมได้ เพื่อรักษาผลงานและความสามารถในการทำซ้ำ แต่โปรไฟล์ที่ถูกแช่ใช้กับโปรเจกต์ใหม่หรือแก้ Brand Profile ไม่ได้จนกว่าจะอัปเกรด

## ขอบเขตการส่งมอบ

### Quality Gate ก่อนสร้าง UI

- Visual Format Benchmark 15 ภาพ
- Brand Differentiation Benchmark 6 ภาพด้วย Mewsocial เทียบ control
- แนวที่ไม่ผ่านถูกแก้สูตรหรือถอดจาก V1

### V1

- Visual Format หลัก 5 แบบและการ์ดเปรียบเทียบ
- Content Preflight + Visual Beats สำหรับ AI script, สคริปต์ที่ผู้ใช้ใส่เอง และ transcript จากวิดีโออัปโหลด
- Project Look และ Suggested Treatment ใน Step 2
- Brand Library, Brand Profile, Draft และ immutable Revision
- ค่าเริ่มต้นสคริปต์ เสียง Subtitle โลโก้/ลายน้ำ และ Brand Visual Language ที่ override รายคลิปได้
- ภาพไม่มีตัวอักษร, Z-Image เส้นทางเดียว, 2 เครดิตต่อภาพ
- Starter AI Image Allowance 8 ภาพต่อ usage window และ Free Brand Profile 1 โปรไฟล์
- กติกาแก้สคริปต์ เปลี่ยนแนวภาพ reroll และ downgrade ที่เคาะในเอกสารนี้

### Fast-follow

- หมวด “กำลังนิยม” สำหรับลูกค้า
- หลังบ้านสร้าง เผยแพร่ กำหนดวัน และถอด Trend Pack
- ความสามารถให้โมเดลอนาคตเขียนข้อความในภาพ

### Rollout

1. เปิดให้บัญชี production `duckyhero`, Admin และบัญชีทดสอบ Free เพื่อผ่าน e2e ของ Brand จริงและ entitlement ของ Free
2. เปิดให้ผู้สมัครใหม่ 10% ตั้งแต่เริ่ม PRO Trial โดยใช้ cohort ที่คงที่ ช่วงนี้เป็น canary ด้านงานเจน, การคืนสิทธิ์/เครดิต และ RunPod COGS ไม่ใช้ Paid conversion เป็นตัวบล็อกเพราะ sample เล็กเกินไป
3. เมื่อ safety guardrails ผ่าน ขยาย treatment เป็น 50% เพื่อวัดอัตราเริ่ม→เจนคลิปสำเร็จและอัตราบันทึก Brand Profile เทียบ control
4. เปิดเต็มเมื่อผ่านเกณฑ์ที่กำหนด ไม่มีการเปิดทุกบัญชีพร้อมกันหรือเปิดเฉพาะแผนจ่ายเงินจนเสียโอกาสทดสอบ funnel Starter → Paid

Safety canary 10% ผ่านเมื่อมีข้อมูลอย่างน้อย 100 งานภาพและครบทุกข้อดังนี้:

- งานภาพอย่างน้อย 95% จบเป็นภาพที่ระบบนำไปใช้ในคลิปได้หลัง automatic retry
- งานที่ไม่สำเร็จ 100% คืนสิทธิ์ทดลองภาพ AI หรือเครดิตอย่างถูกต้อง
- ไม่พบการหักซ้ำ ยอดติดลบ หรือ reservation ที่ค้างเกิน 30 นาทีแม้แต่รายการเดียว
- RunPod COGS เฉลี่ยไม่เกิน ฿0.30 ต่อภาพ และค่าเฉลี่ยรายวันไม่เกิน ฿0.50 ต่อภาพ

Canary บันทึกเวลา end-to-end แบบ P50/P95 แต่ยังไม่ใช้ latency เป็นตัวบล็อกในรอบแรก เพราะยังไม่มี baseline ที่รวม cold start และ queue time จริง เมื่อครบ 100 งานจึงใช้ข้อมูลนี้กำหนด SLA สำหรับช่วง 50% โดยไม่ลดเกณฑ์ด้านเครดิต ความสำเร็จ และต้นทุนข้างต้น

Treatment 50% เปิดเต็มเป็น 100% เมื่อ safety guardrails ข้างต้นยังผ่านต่อเนื่อง และมีผู้สมัครใหม่ที่มาถึง Step 2 อย่างน้อย 100 คนต่อ cohort แล้วครบทั้งสองข้อดังนี้:

- อัตราเรนเดอร์คลิปแรกสำเร็จภายใน 24 ชั่วโมงของ treatment ต่ำกว่า control ได้ไม่เกิน 5 จุดเปอร์เซ็นต์ เพื่อยืนยันว่าตัวเลือกแนวภาพไม่ได้เพิ่มความฝืดจนทำให้การสร้างคลิปหลักเสียหาย
- ในกลุ่ม treatment ที่สร้างคลิปแนวภาพสำเร็จ อย่างน้อย 20% ต้องกดบันทึกแนวนั้นเป็น Brand Profile หรือกลับมาใช้แนวเดิมกับอีกโปรเจกต์ภายใน 7 วัน โดยนับผู้ใช้หนึ่งคนเพียงครั้งเดียวแม้ทำทั้งสองอย่าง

Paid conversion ไม่ใช่เงื่อนไขเปิด 100% ในช่วงนี้ แต่ยังติดตามแยกตาม cohort ต่อไปเพื่อประเมินผลทางธุรกิจระยะยาว

North-star คืออัตราผู้สมัครใหม่ที่ได้รับฟีเจอร์ตั้งแต่ PRO Trial และอัปเกรดเป็น Paid ภายใน 7 วันหลังเจนคลิปแนวภาพสำเร็จครั้งแรก เทียบกับ control cohort ที่ยังไม่ได้ฟีเจอร์ แต่ production baseline ณ 2026-08-09 มีผู้สมัครที่ผ่านช่วงสังเกต 860 คนและจ่ายใน 7 วันเพียง 6 คน (~0.7%) จึงติดตาม North-star ระยะยาวและไม่ใช้บล็อก rollout ระยะแรก ตัวชี้วัดนำคืออัตราเริ่ม→เจนคลิปสำเร็จ, อัตราบันทึก Brand Profile, reroll ต่อภาพ, งานล้มเหลว/คืนสิทธิ์ และ RunPod COGS ต่อผู้ใช้ที่ activate

## แก้ไขภายหลัง (2026-08-10)

Mew พบข้อบกพร่องในการทำงานจริงของ Hero AI Image ตามที่บันทึกไว้ใน
`docs/plans/2026-08-10-brand-visual-storytelling-fix.md` และ `docs/adr/0006-brand-visual-language-controls-rendering-not-scene.md`
สองบรรทัดในหัวข้อ "การตั้งค่า Brand Profile" ของเอกสารนี้ถูกยกเลิกผลบังคับใช้:

- "เพิ่มจุดจำทางภาพ"
- "ระบุคนหรือฉากแวดล้อมที่ใช้บ่อย"

ทั้งสองบรรทัดเป็น input ที่ระบุเนื้อหาของฉาก (subject/prop/location) ซึ่งขัดกับหลักการใหม่ว่า
Brand Visual Language ควบคุมเฉพาะ "ภาพถูกเรนเดอร์อย่างไร" ไม่ใช่ "อะไรอยู่ในภาพ" — Visual Beat
เป็นเจ้าของเนื้อหาฉากแต่ผู้เดียว ดูรายละเอียดการตัดสินใจและผลกระทบใน ADR 0006 และแผนที่อ้างถึงข้างต้น
ข้อความเดิมในเอกสารนี้ไม่ถูกแก้ไข ส่วนนี้เป็นส่วนเสริมภายหลังเท่านั้น

ต่อมา Mew พบว่าข้อความในหัวข้อ "ขอบเขตการส่งมอบ" ที่ว่า **"ภาพ AI ทุกแนวใน V1 เป็นภาพไม่มีตัวอักษร"**
ก็ไม่เป็นจริงตามที่บันทึกไว้เช่นกัน ตามที่บันทึกไว้ใน `docs/plans/2026-08-10-image-text-policy.md` และ
`docs/adr/0007-generated-image-text-policy.md` ข้อความนี้ถูกยกเลิกผลบังคับใช้ในฐานะ absolute เช่นกัน
ตัวเลขและตัวอักษรที่เป็นส่วนหนึ่งของวัตถุในภาพ (เช่นตัวเลขบนธนบัตรหรือป้ายราคา) และตัวอักษรภาษาอังกฤษ
ได้รับอนุญาต ส่วนที่ยังคงห้ามคือตัวอักษรไทยในภาพที่โมเดลสร้าง เพราะโมเดลวาดตัวอักษรไทยที่ดูจริงแต่อ่าน
ไม่ได้ความ ข้อความที่คนดูต้องอ่านและทำตามยังคงเป็นหน้าที่ของ subtitle/headline/brand-mark layer เหมือนเดิม
ไม่เปลี่ยนแปลง ดูรายละเอียดการตัดสินใจและเหตุผลด้าน enforcement ใน ADR 0007 ข้อความเดิมในเอกสารนี้ไม่ถูก
แก้ไข ส่วนนี้เป็นส่วนเสริมภายหลังเท่านั้น
