# HERO AI Marketing SOP

This folder is the source of truth for HERO AI content marketing work handled by Codex agents.

Start here:

- `content-marketing-sop.md` - end-to-end workflow from update selection to image generation, QA, and FeedHive publishing.
- `brand-ci.md` - brand visual rules and copy constraints.
- `imagegen-prompt-pack.md` - reusable prompts for ChatGPT image generation.
- `campaigns/2026-07-06-v1-2-0-cold-audience.md` - concrete example from the first published campaign.

Security rule: never commit API keys, FeedHive tokens, signed upload URLs, OTPs, or production credentials. Use temporary shell variables only.
