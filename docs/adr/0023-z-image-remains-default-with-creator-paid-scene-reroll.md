# Z-Image remains the default with creator-paid Scene Reroll

Date: 2026-08-18
Status: Accepted; supersedes only the release disposition in ADR 0021 and ADR 0022

The 120-image V10 matrix and 18-image V11 focused probe remain valid evidence
that Z-Image does not deterministically satisfy the strict Hard Scene Fact gate.
The product nevertheless accepts Z-Image as the Brand Visual V1 default because
its delivered cost is approximately ฿0.175 per image, while the focused model
comparison did not establish a sufficiently economical replacement. This does
not relabel the strict failures as passes or promise exact counts, anatomy,
physical contact, lettering, face identity or character identity.

Brand Visual V1 therefore uses pragmatic creator acceptance at the product
boundary. Each initial B-roll window requests exactly one image and performs no
hidden quality retry, generic-treatment fallback or AI Engine switch. A creator
who wants another result explicitly chooses `Scene Reroll / ลองภาพนี้ใหม่` for
that Visual Beat. Each new request is one new billable generation at the existing
two-credit price; replaying the same durable request never creates or charges a
second image, and an undelivered request restores its exact allowance or credit
buckets. The existing asset remains intact until the replacement derivative is
successfully delivered and deliberately applied.

Scene Reroll ships to every capable project in the existing Paid Public Launch;
it has no separate internal-only or 10% → 50% → 100% cohort. Existing PRO,
BUSINESS, paid Bundle, GRANT coupon and Administrator Grant access must not be
reduced for this release. A successful discounted or Founding Price purchase is
cash-backed paid access exactly like a full-price purchase—the discount changes
price, not capability. A DISCOUNT coupon without a completed payment grants
nothing by itself. Operational deployment remains separately authorized, and
the strict qualification reports stay immutable for future compiler or model
improvements.
