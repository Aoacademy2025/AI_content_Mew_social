# Character identity is stable while story looks are versioned

Hero Story Film separates a character's stable Identity Core from story-dependent Character Looks. Storyboard planning proposes and assigns a Character Look Plan, and Mew approves its descriptions before generation. Each new Look then produces one Look Keyframe that must pass the Look Approval Gate before any assigned Scene Keyframe is generated; those scenes pin the same Character Look Revision until an intentional narrative transition. A project-specific Look remains local to that project unless Mew explicitly saves it to Character Library. This keeps Mew's face stable while allowing every story to change wardrobe, styled hair, accessories, era and palette without multiplying character identities or drifting costumes mid-sequence.
