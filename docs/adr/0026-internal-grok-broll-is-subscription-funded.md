# Internal Grok B-roll is subscription-funded and non-public

Generated Grok image and video B-roll must consume Mew's authorized Grok subscription allowance rather than the separately billed xAI API or Hero customer Credits. Phase 1 is an owner-operated Mew-only pilot: only Mew may submit work, while team-triggered and public customer generation are excluded. This deliberately trades public scalability and provider determinism for reuse of the subscription-backed Grok CLI path already proven in `mewcontent`; the lane remains isolated from customer-facing generation and fails closed when no authorized subscription worker is available.
