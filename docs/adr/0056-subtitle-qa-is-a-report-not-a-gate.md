# Subtitle QA is a report, not a gate

Between 2026-08-27 and 2026-08-30 the TTS-voice subtitle path (Gemini voice, Hero AI Voice) was changed from the fail-open architecture locked in June ("timing comes from the TTS step, exact by arithmetic; every layer fail-open") to a fail-closed one: estimated segment clocks became `unverified_alignment`, every Gemini render ran an ASR pass over its own narration, fuzzy Thai text matching decided whether the clip could be released, an alignment verdict could regenerate the TTS, and Export re-ran the same gate on the creator's edited captions. Production create failures rose from ~17 % to 59 % in one day and Export — a zero-failure path for the previous eight days — failed 27–56 % of the time (`docs/audits/2026-08-30-subtitle-render-stability-audit.md`). The sync complaint that motivated the work was real, but the gates did not make a single clip more accurate; they only converted "a few cards are 1–3 s early" into "no clip at all".

**Decision.** A Subtitle QA Report is produced for every render and every export and is persisted with the job (`subtitleQa`, `subtitleEvidence`). It has three statuses: `passed`, `warning`, `failed`. Only a **Blocking Subtitle Code** — `empty_script`, `empty_captions` (nothing to show) — yields `failed` and stops the job. Every other finding (unverified timing, text drift, coverage, density, overlaps, blank cards, short cards) is a `warning`: timing is repaired deterministically where possible, the clip proceeds, and the report is what the editor surfaces in the Post phase.

The render clock for Gemini and Hero AI Voice follows a fail-open ladder: **one** bounded acoustic alignment call (transcribe + alignment of the known script to the narration, inside a wall-clock budget) — when it succeeds its word timing is the render clock (`forced_alignment`; measured on production it cuts cards more than 1 s off from ~11 % to 1.3 %); when it fails or times out the provider's deterministic segment clock (`tts_segment_timing`) renders; when the provider returned no timing the char-proportional spoken-script clock renders. Every rung is recorded in the report together with the clock that was not used, so accuracy can be compared later. No alignment verdict may trigger provider spend (TTS regeneration), a retry the creator did not ask for, or a refusal. Export never re-aligns and never rejects a creator's text edit; a blank card is dropped, not refused.

**Consequences.** Subtitle accuracy work changes the *source of timing* (a real word-level alignment of the known script to the audio, evaluated against the persisted verification evidence) and ships as a better clock behind the same report — never as a new gate. A verification path that is not measured by telemetry (duration, method, per-card delta) is not eligible to influence anything. Test fixtures assert that a `warning` job completes; a suite that asserts a subtitle-only failure is a policy bug, not a regression test. This ADR restores and supersedes the June invariant recorded in `STATUS.md` ("ทุกชั้นมี fail-open → ห้าม 'ซ่อม' โดยเอา transcribe กลับมาเป็น path หลัก").
