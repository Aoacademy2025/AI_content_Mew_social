# Character Library is private, versioned and independent of Brand Library

Hero AI Studio owns an account-private Character Library for reusable Hero Story Film identities. A character stores private references, durable identity facts and a permission record in immutable Character Revisions; projects pin the revision they use, while a Brand Profile may only select a default. Reference originals remain outside public media paths, and the Grok worker downloads them through short-lived signed grants for authorized jobs before attaching them only to assigned character scenes. The Mew-only pilot registers Mew's two existing clean references as `Mew v1` through this same product path, testing the public-ready identity workflow rather than relying on worker-local file aliases.
