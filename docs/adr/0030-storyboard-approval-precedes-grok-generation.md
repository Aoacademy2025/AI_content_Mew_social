# Storyboard approval precedes Grok generation

The Internal Grok B-roll Lane stops after Content Preflight presents an asset-free Storyboard Draft and requires Mew's explicit approval before queuing any Grok image or video generation. Mew can first correct scene order, timing, continuity, appearances and intended media types; changes that alter story meaning invalidate approval for the affected sequence. This gives up one-click generation to avoid spending bounded subscription capacity and worker time on a coherent but unwanted story direction.
