# Story shape adapts without forcing fiction

Content Preflight selects one Narrative Adaptation Mode before planning the Narrative B-roll Sequence. Naturally event-led material uses Story Film, while news, how-to and explanatory material uses Cinematic Visual Essay: both preserve cross-scene continuity, but the essay mode advances a visual argument instead of inventing a fictional plot. This keeps the short-film craft where the source supports it while preventing cinematic style from fabricating events or turning generated frames into evidence.
