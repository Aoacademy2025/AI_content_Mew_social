## 🚀 Deploy runbook (ทำตอนเปิด E2E + go-live พร้อมกัน · coordinate กับ wao1234 — `schema.prisma`/`ecosystem.config.js` แชร์)

> **ลำดับสำคัญ** — `deploy/deploy.sh` รัน `prisma generate` แต่ **ไม่รัน `db push`**.

1. `cp prisma/dev.db prisma/dev.db.bak-$(date +%F)` (backup)
2. `npx prisma db push` บน VPS → เพิ่ม **model `FoundingReservation` + 2 คอลัมน์ `trialStartedAt`/`trialEndsAt`** ทีเดียว (additive ทั้งหมด ไม่เสียข้อมูล)

5. สร้าง coupon `FOUNDING100` **live** ผ่าน admin: `type:DISCOUNT, percentOff:50, discountDuration:forever, maxUses:100` (อย่า restrict product) — **หลัง db push เท่านั้น**
6. E2E จ่ายจริง test mode (pricing banner + counter, จ่าย → seat confirmed, abandon → released; signup → trial banner → revert)

## 🔧 หมายเหตุเทคนิค (non-obvious)

- **ไม่มี test runner** ในโปรเจกต์ — พิสูจน์ logic ด้วย `tsx` script (`scripts/verify-*.ts`) รันกับ throwaway SQLite + build + Stripe test mode (ตาม pattern ทีม). ไม่ได้ยัด vitest/jest เข้ามา.
